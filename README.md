# Introduction
This project explores data cleaning in the real estate space


# Background
As a real estate marketing and sales executive, this project was born from a data generated by CHATGPT that centers around Ghana Real Estate

## The questions I seek to answer
## Market
Which locations have the highest average property prices?
Which locations have the most listings?
Which property types dominate the market?
What's the average price by bedroom count?
What's the average price per sqft?
Which locations offer the best?

## Sales
Which agents have the most listings?
Which agents have the highest proportion of sold properties?
Which properties have been sitting on the market longest?
Does price appear related to days on the market?

## Investment 
Which locations appear attractive based on price/sqft?
What property types command the highest premiums?
Are expensive properties necessarily larger?
Which segments could represent an opportunity?
