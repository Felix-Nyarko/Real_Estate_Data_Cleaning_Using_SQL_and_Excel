1. Standardizing the string columns such as location, property type, status, furnished, agent name and source
```sql 
SELECT
      TRIM(INITCAP(location)) AS cleaned_location,
      TRIM(INITCAP(property_type)) AS cleaned_property_type,
      TRIM(INITCAP(status)) AS cleaned_status,
      TRIM(INITCAP(furnished)) AS cleaned_furnished,
      TRIM(INITCAP(agent_name)) AS cleaned_agent_name,
      TRIM(INITCAP(source)) AS cleaned_source
FROM
      `new-tutorials.Real_Estate_Data_Set.Real_Estate`;
```
The above code is not applicable in MYSQL Workbench

Alternatively, the case statement can be applied to standardize the string columns;
```sql
SELECT
      property_type,
CASE 
      WHEN lower(property_type) like '%ment%' THEN 'Apartment'
      WHEN lower(property_type) like '%house%' THEN 'House'
      WHEN lower(property_type) like '%penthouse%' THEN 'Penthouse'
      WHEN lower(property_type) like '%studio%' THEN 'Studio'
      WHEN lower(property_type) like '%town%' THEN 'Townhouse'
      ELSE 'other'
      END AS cleaned_property_type
FROM
      real_estate_sql_cleaning.messy_real_estate_listings_ghana;
```
it is applicable to workbench

3. Finding duplicates
```sql
SELECT
   property_id, location, property_type, bedrooms,
   row_number () OVER (
   partition by location, property_type
   order by property_id)
   AS rn
FROM 
   real_estate_sql_cleaning.messy_real_estate_listings_ghana;
```

4. Finding and removing duplicates
```sql
SELECT
   *
FROM 
   (SELECT property_id, location, property_type, bedrooms,
   row_number () OVER (
   partition by location, property_type
   order by property_id)
   AS rn
from 
   real_estate_sql_cleaning.messy_real_estate_listings_ghana) AS rn
where
   rn=1;
```

5. Finding and replacing negative values - Location
```sql
SELECT
   TRIM(REPLACE(INITCAP(location),'-',' ')) AS location_cleaned,
   count(*) as property_count
FROM
   `new-tutorials.Real_Estate_Data_Set.Real_Estate`
GROUP BY location_cleaned
ORDER BY property_count DESC;
```

6. Finding and replacing negative values - Area Sqft
```sql
SELECT
    area_sqft,
    REPLACE(area_sqft, '-', '') AS area_sqft_cleaned
FROM
   real_estate_sql_cleaning.messy_real_estate_listings_ghana
WHERE
   area_sqft IN (-120, -500);
```

   i. Identifying where the nulls are
   2. Deciding what to do with the null
   3. replacing nulls with meaninful values (using coalesce)
   4. Filling the null based on a business generated from the data

The Market
1. The locations that have the highest average property prices
To identify the locations that have the highest average property prices, I filtered....
```sql
SELECT Location,
   ROUND(AVG(` Price_GHS `), 0) AS Avg_Property_Price 
FROM
   `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE
   Location IS NOT NULL
   AND ` Price_GHS ` IS NOT NULL
GROUP BY
   Location
ORDER BY
   Avg_Property_Price DESC
LIMIT 10;
```

```sql
SELECT
  Bedrooms,
  COUNT(Bedrooms) AS Bedroom_Count,
```

4. Does price appear related to days on the market?
```sql
SELECT
  ` Price_GHS `,
    Days_On_Market
FROM `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE ` Price_GHS ` IS NOT NULL AND
    Days_On_Market IS NOT NULL AND
    ` Price_GHS ` > 0 AND
    Days_On_Market > 0
ORDER BY Days_On_Market DESC;
```

To further determine the correlation between price and days on the market, we can use correlation.
```sql
SELECT
  CORR(Price_GHS, Days_On_Market) AS price_days_correlation
FROM
  `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE
  Price_GHS IS NOT NULL
  AND Days_On_Market IS NOT NULL
  AND Price_GHS > 0
  AND Days_On_Market >= 0;
```
The correlation coefficient was -0.0233 signifying that there is no relationship that exist between price and days on the market about this dataset
The correlation between property price and days on market was -0.026, indicating a negligible negative linear relationship. This suggests that property price alone does not appear to have a meaningful linear association with how long a property remains on the market in this dataset.


### Investment 
1. Which locations appear attractive based on price/sqft?
The locations that appear attractive based on price/sqft
```sql
SELECT
    Location,
    ROUND(AVG(` Price_GHS `/Area_ft), 2) AS average_price_per_sqft
FROM
  `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
  WHERE Location IS NOT NULL AND
  ` Price_GHS ` IS NOT NULL AND
  Area_ft IS NOT NULL
  AND ` Price_GHS ` > 0
  AND Area_ft > 0
GROUP BY
   Location
ORDER BY
   average_price_per_sqft DESC;
```
