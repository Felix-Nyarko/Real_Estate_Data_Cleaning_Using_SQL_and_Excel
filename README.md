```sql 
      TRIM(INITCAP(location)) AS cleaned_location,

      `new-tutorials.Real_Estate_Data_Set.Real_Estate`;
```


```sql
SELECT
```

The correlation between property price and days on market was -0.026, indicating a negligible negative linear relationship. This suggests that property price alone does not appear to have a meaningful linear association with how long a property remains on the market in this dataset.

### 3. Are expensive properties necessarily larger?
To determine whether expensive properties are necessarily larger, first we need to examine the relationship between property price and property area using correlation.
```sql
SELECT
  CORR(` Price_GHS `, Area_ft) AS Price_Area_Correlation
FROM
  `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE
  ` Price_GHS ` IS NOT NULL
  AND Area_ft IS NOT NULL
  AND ` Price_GHS ` > 0
  AND Area_ft > 0;
```
**The correlation coefficient is 0.1664**. Since the correlation coefficient is greater than 0 but less than 1, it signifies there is a little linear relationship that exist between property price and property area(size). 

Alternatively,
```sql
SELECT
  CASE
    WHEN Area_ft < 800 THEN 'Small (<800 sqft)'
    WHEN Area_ft < 1500 THEN 'Medium (800–1499 sqft)'
    WHEN Area_ft < 2500 THEN 'Large (1500–2499 sqft)'
    ELSE 'Extra Large (2500+ sqft)'
  END AS Property_Size,
  COUNT(*) AS Number_of_Properties,
  ROUND(AVG(` Price_GHS `), 2) AS Average_Price_GHS
FROM
  `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE
  ` Price_GHS ` > 0
  AND Area_ft > 0
GROUP BY
  Property_Size
ORDER BY
  CASE Property_Size
    WHEN 'Small (<800 sqft)' THEN 1
    WHEN 'Medium (800–1499 sqft)' THEN 2
    WHEN 'Large (1500–2499 sqft)' THEN 3
    ELSE 4
  END;
```

From the above table, to buttress the linear relationship that exist between price and property size, it is evident that as the size of the property increases, the average property price increases as well

### 4. Which segments could represent an opportunity?
```sql
SELECT
  Location,
  Property_Type,
  COUNT(*) AS Number_of_Properties,
  ROUND(AVG(` Price_GHS `), 2) AS Average_Price_GHS,
  ROUND(AVG(` Price_GHS ` / Area_ft), 2) AS Average_Price_Per_Sqft,
  ROUND(AVG(Days_On_Market), 1) AS Average_Days_On_Market
FROM
  `new-tutorials.Cleaned_Real_Estate_Data.Real Estate Analysis`
WHERE
  Location IS NOT NULL
  AND Property_Type IS NOT NULL
  AND ` Price_GHS ` > 0
  AND Area_ft > 0
  AND Days_On_Market >= 0
GROUP BY
  Location,
  Property_Type
HAVING
  COUNT(*) >= 5
ORDER BY
  Average_Price_Per_Sqft ASC,
  Average_Days_On_Market ASC;
```
